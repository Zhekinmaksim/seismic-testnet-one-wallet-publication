# Seismic Testnet One-Wallet Publication

This repository packages one clean Seismic testnet case study for public sharing.

It includes:

- a concise step-by-step guide
- a polished article built around one real wallet run
- a finished PNG slide deck for X/Twitter

## Contents

- [Guide](./publication/guide.md)
- [Article](./publication/article.md)
- [Slides](./publication/slides)

## Scope

The material is based on one completed Seismic testnet flow that covered:

- deployment of three contracts
- shielded writes
- signed reads
- private token transfer
- Walnut flow
- Directory viewing key registration
- Mercury precompile checks
